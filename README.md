# سونو دارا · الإدارة (نموذج تجريبي)

تطبيق مستقل لإدارة المدارس القرآنية بنظام النقاط: رصيد نقاط يُشترى ويُستهلك مع كل تسجيل أو تصدير.

## الملفات (ارفعها كما هي في جذر المستودع)
- `index.html` · `style.css` · `app.js` · `logo.jpg` · `README.md`

## النشر
- **Vercel:** استورد المستودع، واختر Framework Preset: **Other**، واترك أمر البناء (Build Command) فارغًا.
- **GitHub Pages:** Settings ← Pages ← Branch `main` / المجلد `/ (root)`.

## ملاحظات
- كل البيانات والدفع تجريبية؛ تُحفظ الحالة في متصفح الجهاز فقط (localStorage).
- الأسعار (نقطة لكل جلسة، تقارير 5/20/50) في أعلى `app.js` ثابت `COST`، ويمكن تعديلها.

- **دون إنترنت:** يستمر التسجيل والتقارير على الهاتف، وتُعلَّم العمليات «بانتظار المزامنة» ثم تُزامَن عند عودة الاتصال. شراء النقاط يحتاج إنترنت. وفي «المزيد» مفتاح لمحاكاة ذلك.

- **الشبكة:** وظائف وخدمات (النشر المدفوع 20 نقطة، وإعلان «أبحث عن عمل» مجاني)، ودليل معلمين بشارة «موثّق من الدارة»، وأزرار اتصال وواتساب. لا تظهر فيها بيانات التلاميذ.

- **التثبيت كتطبيق (PWA):** بعد النشر افتح الرابط في Chrome على الأندرويد ثم «إضافة إلى الشاشة الرئيسية». الملفات `manifest.json` و`sw.js` والأيقونتان تجعله يُثبَّت ويفتح دون إنترنت.
- كل الأيقونات مرسومة داخل `app.js` (SVG)، ولا تعتمد على أي مكتبة خارجية. الخط فقط (تجوال) يُحمَّل من Google Fonts.
